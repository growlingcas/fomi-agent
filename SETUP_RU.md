# Запуск FOMI — по шагам

## Как это устроено
- **Сайт** (`docs/`) — GitHub Pages. Экран 1 — живой облачный телефон VMOS с приложением fomo. Экран 2 — её ресёрч. Ниже мозг, банк, журнал.
- **Мозг** (`brain/`) — ищет токены, считает сигналы, решает, ведёт банк, учится.
- **Телефон** — VMOS Cloud через их OpenAPI: живое превью экрана, нажатия (`input tap`), ввод текста, запуск приложения.
- **Live-сервер** (`npm run live`) — на VPS 24/7: мозг + телефон + поток событий на сайт. Ключи VMOS живут только здесь.

## 0. Безопасность ключей
Ключи VMOS, которые были в чате, — **перевыпусти** в кабинете (Developer → API) и используй новые.
Кладутся только в `.env` на сервере. В репозиторий и на сайт — никогда. Если заливаешь на GitHub через браузер, убедись, что файла `.env` в папке нет.

## Быстрая проверка у себя на компьютере
Нужен Node.js 18+.
```
cd fomi-agent
npm install
npm run phone:ping        # проверка ключей VMOS → кадр в brain/data/phone/ping.jpg
npm run live              # мозг + телефон + сайт
```
Открой **http://localhost:8787** — экран 1 покажет живой облачный телефон (если `phone:ping` прошёл), экран 2 — её ресёрч.
По умолчанию `PHONE_DRY_RUN=1`: она ходит по приложению, но ничего не подтверждает.

## 1. Сайт
1. Залей репозиторий на GitHub (без `.env`).
2. Settings → Pages → `main` / `/docs`.

## 2. Телефон
1. В облачном телефоне VMOS установи fomo, войди, пополни кошелёк (~$10 на старт).
2. На сервере:
```
cp .env.example .env
# впиши VMOS_AK, VMOS_SK, VMOS_PAD_CODE и START_BANK_SOL = сколько реально на кошельке
npm run phone:ping
```
Если всё ок — в `brain/data/phone/ping.jpg` будет кадр с телефона.

## 3. Научить её интерфейсу fomo (один раз)
1. Открой в телефоне страницу любого токена в fomo.
2. `npm run phone:snap` — сохранит `screen.jpg` и `elements.txt` (все кнопки с текстом и координатами).
3. Повтори для: поиска, окна покупки, окна подтверждения, окна продажи, окна тезиса.
4. Пришли мне эти файлы + имя пакета приложения (`elements.txt` его покажет) — заполню `brain/phone/fomo-ui.json`.

Сначала она пробует открыть токен напрямую ссылкой `fomo.family/tokens/solana/<CA>` — если приложение перехватывает такие ссылки, поиск вообще не нужен.

Проверка без денег:
```
npm run phone:test -- <CA токена> <ТИКЕР> 0.005
```

## 4. VPS
```
docker build -t fomi .
docker run -d --restart=always --env-file .env -p 8787:8787 -v $(pwd)/brain/data:/app/brain/data fomi
```
Поставь перед ним https (Cloudflare / Caddy) и впиши адрес в `docs/index.html` → `CONFIG.liveUrl`.

## 5. Реальные сделки
1. Первые пару часов `PHONE_DRY_RUN=1` — смотришь на сайте, что она нажимает правильные кнопки.
2. Потом `PHONE_DRY_RUN=0`.
3. Аварийная остановка: `npm run stop` (снять — `npm run unstop`).

## Банк на $10
В `.env.example` уже стоит пресет: ставка 0.005–0.015 SOL, резерв 0.01 SOL, стоп при equity ниже 0.03 SOL.
Проверь минимальную сумму сделки и комиссию в fomo: на сделках в пару долларов комиссия может съедать заметный процент.

## GMGN (тренды, smart money, rug ratio, холдеры)
1. На компьютере: `npx gmgn-cli config` — создаст пару ключей и покажет публичный ключ.
2. На gmgn.ai/ai → Create API Key: вставь публичный ключ, Label любой, **Enable Reading — вкл, Enable Trading — выкл**.
3. Скопируй API Key в `.env` → `GMGN_API_KEY=...`.
4. Проверка: `npm run gmgn:check` (должно вывести 3 трендовых токена).
Если 401/403 при правильном ключе — у GMGN работает только IPv4, отключи IPv6 на сервере.

Приватный ключ из шага 1 нам не нужен (он только для торговли через GMGN) — никому его не отправляй.

## Твиттер
Постишь сам: готовые тексты копятся в `brain/data/outbox.json` и в логе на сайте.
